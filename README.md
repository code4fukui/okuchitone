# okuchitone
日本語のREADMEはこちらです: [README.ja.md](README.ja.md)

okuchitone is a web-based application that uses the MediaPipe Face Mesh solution to detect facial landmarks and generates tones based on the position of the lips.

## Demo
https://code4fukui.github.io/okuchitone/

## Features
- Generates tones based on the position of the lips
- Supports multiple faces (up to 5)
- Allows mirroring and back-camera mode
- Displays the original image or just the landmarks

## Requirements
None. The application runs in a web browser.

## Usage
1. Open the [demo page](https://code4fukui.github.io/okuchitone/) in a web browser.
2. Click the "SOUND START" button to start the application.
3. The application will detect your face and generate tones based on the position of your lips.
4. You can adjust the settings (show original image, mirror mode, back-camera mode) using the checkboxes.
