# okuchitone
English README is available here: [README.md](README.md)

okuchitone は MediaPipe Face Mesh ソリューションを使用してフェイシャルランドマークを検出し、唇の位置に基づいてトーンを生成するウェブベースのアプリケーションです。

## デモ
https://code4fukui.github.io/okuchitone/

## 機能
- 唇の位置に基づいてトーンを生成する
- 複数の顔(最大5つ)をサポートする
- ミラーリングとバックカメラモードを可能にする
- オリジナルの画像や、ランドマークのみを表示する

## 要件
アプリケーションはウェブブラウザ上で動作するため、特別な要件はありません。

## 使用方法
1. [デモページ](https://code4fukui.github.io/okuchitone/)をウェブブラウザで開きます。
2. 「SOUND START」ボタンをクリックしてアプリケーションを起動します。
3. アプリケーションがあなたの顔を検出し、唇の位置に基づいてトーンを生成します。
4. チェックボックスを使って設定(オリジナルの画像の表示、ミラーモード、バックカメラモード)を調整できます。
